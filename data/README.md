# Acquired scenario fixtures

Three NASim benchmark YAML files (tiny, small, medium) and the upstream MIT license are stored in raw/nasim. Exact source URLs, commit, retrieval timestamps, byte sizes and SHA-256 hashes are in download-manifest.json. These are unchanged public simulation inputs, not collected outcome data.

The source repository is https://github.com/Jjschwartz/NetworkAttackSimulator. Commit: 4f26de37cfdc3e4553ed8b7484c4db8e2924bdea. The simulator models network attacks and scanning. Patching, observation lineage and stale-evidence experiments require an explicit research adapter. No simulator execution or real-network validation is claimed here.

Original research work remains unlicensed; the bundled third-party files retain their MIT license. Public security catalogs may later provide context, but KEV membership and CVSS values must not be treated as per-edge attack-success probabilities or remediation labels.
